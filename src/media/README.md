# Media archive

Drop files anywhere in this folder to display them in the site archive. Extensions are case-insensitive: `POSTER.PNG` and `poster.png` are handled the same way.

## Supported types

| Kind | Extensions |
| --- | --- |
| Images | `.avif`, `.gif`, `.jpeg`, `.jpg`, `.png`, `.svg`, `.webp` |
| Videos | `.mov`, `.mp4`, `.webm` |

Unsupported files are ignored. File names become the visible titles: hyphens, underscores, and repeated spaces are normalized, while the original file URL stays unchanged. Use descriptive names such as `canva-poster-spring-2026.png`.
